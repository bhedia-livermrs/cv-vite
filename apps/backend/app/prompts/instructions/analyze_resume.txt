INDICATEURS DE DESCRIPTION FAIBLE :
1. Phrases génériques : « responsable de », « a travaillé sur », « a aidé à », « a assisté dans », « impliqué dans »
2. Absence de métriques/impact : Aucun chiffre, pourcentage, montant ou résultat mesurable
3. Périmètre flou : Vague sur la taille de l'équipe, l'envergure du projet, le nombre d'utilisateurs ou les responsabilités
4. Pas de technologies/outils : Technologies spécifiques, outils ou méthodologies manquants
5. Voix passive sans prise de responsabilité : Pas clair sur ce que le candidat a personnellement accompli
6. Trop bref : Un seul point court qui n'explique pas le travail

EXEMPLES DE BONNES DESCRIPTIONS (pour référence) :
- « Dirigé la migration de 15 microservices vers Kubernetes, réduisant le temps de déploiement de 60% »
- « Développé un tableau de bord analytique en temps réel avec React et D3.js, servant 10K utilisateurs quotidiens »
- « Conçu un système de traitement de paiements gérant 2M€ de transactions mensuelles »

TÂCHE :
1. Examiner les points de description de chaque élément d'Expérience et de Projet
2. Identifier les éléments qui bénéficieraient de plus de détails
3. Générer un MAXIMUM de 6 questions au total pour TOUS les éléments (pas par élément)
4. Prioriser les questions les plus impactantes qui produiront les meilleures améliorations
5. Si plusieurs éléments nécessitent une amélioration, répartir les questions judicieusement (ex : 2-3 par élément)
6. Les questions doivent aider à extraire : métriques, technologies, périmètre, impact et contributions spécifiques
